# RetinaGuard — AI/ML Pipeline

This document describes the Python AI training and inference pipeline added in the SIH 2026 upgrade.

## Quick Reference

```bash
# Install Python dependencies (once)
pip install -r python/requirements.txt

# Phase 2: Inspect dataset
python python/dataset/dataset_inspector.py

# Train the model (downloads APTOS once, caches locally)
python python/training/train.py

# Evaluate saved model
python python/training/evaluate.py

# Export to ONNX (for MATLAB)
python python/deployment/export_model.py

# Test single image inference
python python/inference/predict.py path/to/retinal_image.jpg

# Verify the whole Python pipeline
python python/verify_pipeline.py
```

## Architecture

```
python/
├── config/config.yaml          ← ALL hyperparameters in one file
├── dataset/
│   ├── aptos_loader.py         ← HuggingFace load + cache + stratified split
│   ├── aptos_dataset.py        ← PyTorch Dataset wrapper
│   └── dataset_inspector.py   ← Phase 2 inspection script
├── preprocessing/
│   └── retinal_preprocessor.py ← CLAHE + augmentation + normalization
├── models/
│   └── efficientnet_dr.py      ← EfficientNet-B0 transfer learning model
├── training/
│   ├── train.py                ← Full two-stage training loop
│   └── evaluate.py             ← QWK, F1, confusion matrix, referral metrics
├── inference/
│   └── predict.py              ← predictDR() inference API
├── explainability/
│   └── gradcam.py              ← Grad-CAM heatmap generation
├── deployment/
│   └── export_model.py         ← ONNX export + MATLAB wrapper generation
└── verify_pipeline.py          ← End-to-end smoke tests (no dataset needed)
```

## Model

- **Architecture**: EfficientNet-B0 pretrained on ImageNet
- **Training dataset**: bumbledeep/aptos (APTOS 2019 DR images)
- **Output**: 5 DR severity classes (Grade 0–4, ICDR scale)
- **Key metric**: Quadratic Weighted Kappa (QWK)

## Two-Stage Training

| Stage | Epochs | LR | What trains |
|---|---|---|---|
| 1 | 5 | 1e-3 | Classification head only (backbone frozen) |
| 2 | 25 | 1e-4 | Upper 3 backbone blocks + head |

## MATLAB Integration

After training + export:

```matlab
% gradeDR.m automatically detects and loads:
%   models/aptos_efficientnet/best_model.onnx
% via runONNXModel.m (auto-generated by export_model.py)

result = gradeDR(img, lesions, quality, cfg);
% result.demoMode = false when ONNX model is loaded
```

## Class Labels (Fixed — Do NOT Change)

| Grade | Label |
|---|---|
| 0 | No DR |
| 1 | Mild DR |
| 2 | Moderate DR |
| 3 | Severe DR |
| 4 | Proliferative DR |

## Evaluation Outputs

After training, the following files are saved to `results/`:

| File | Contents |
|---|---|
| `dataset_inspection.json` | Dataset structure, class distribution |
| `class_distribution.png` | Bar chart of DR grade counts |
| `training_history.json` | Loss, accuracy, QWK per epoch |
| `training_curves.png` | Loss / accuracy / QWK graphs |
| `confusion_matrix.png` | Normalized confusion matrix |
| `classification_report.txt` | Per-class precision, recall, F1 |
| `metrics_summary.json` | All metrics as JSON |

And to `models/aptos_efficientnet/`:

| File | Contents |
|---|---|
| `best_model.pt` | Best checkpoint (by validation QWK) |
| `best_model.onnx` | ONNX export for MATLAB |
| `metadata.json` | Training date, architecture, QWK |
| `metrics.json` | Final evaluation metrics |
| `config.yaml` | Config snapshot at training time |
| `class_mapping.json` | Grade index → label name |

## Important Disclaimers

- This is an AI-assisted screening prototype, NOT a medical diagnosis system.
- Performance metrics are measured on the validation set only.
- No clinical validation has been performed.
- Never present model predictions as medical diagnoses.
